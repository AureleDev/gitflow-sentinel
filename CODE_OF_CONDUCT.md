# Code de conduite

Gitflow Sentinel accueille les retours critiques, les questions et les
contributions dans un cadre respectueux, constructif et inclusif.

## Comportements attendus

- discuter des faits et du code sans attaquer les personnes ;
- expliquer les désaccords et proposer une voie vérifiable ;
- respecter les niveaux d'expérience, les langues et les contextes différents ;
- protéger les informations privées rencontrées pendant les tests ;
- reconnaître et corriger une erreur lorsqu'elle est démontrée.

Le harcèlement, la discrimination, les menaces, les insultes répétées, le spam
et la publication d'informations privées ne sont pas acceptés.

Ce code s'applique aux issues, pull requests, discussions et autres espaces où
une personne représente le projet. Les mainteneurs peuvent modifier ou retirer
un contenu, fermer une contribution ou restreindre une participation pour faire
respecter ces règles.

Pour signaler un incident, contactez le mainteneur depuis le profil GitHub
[@AureleDev](https://github.com/AureleDev). Ne publiez pas d'information privée
dans une issue. Les vulnérabilités suivent séparément [SECURITY.md](SECURITY.md).
