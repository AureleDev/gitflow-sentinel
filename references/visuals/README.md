La page [`index.html`](index.html) regroupe les six schémas dans un parcours
continu. Elle peut être ouverte directement dans un navigateur ; elle ne charge
aucune ressource distante.

## Lecture rapide

- L’IA inspecte, interprète et explique les choix.
- Sentinel Core planifie, applique, journalise, vérifie et restaure.
- Une approbation est requise avant toute mutation.
- Windows natif est déjà validé. WSL n’est pas requis pour l’usage, mais reste
  utile pour la validation Linux.
- macOS et les actions GitHub réelles restent à valider avant toute promesse de
  compatibilité complète.
